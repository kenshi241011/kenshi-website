Términos y Condiciones

Vigentes desde el 28 de octubre de 2026 · Versión 1.0

Resumen en lenguaje sencillo (no reemplaza el texto completo):

  • La versión gratuita se puede usar sin límite de tiempo. La licencia (3, 6 o 12 meses) es un pago único, no se renueva sola y vale para un equipo.
  • Kenshi Security es una protección complementaria: no reemplaza a Microsoft Defender y ningún antivirus detecta el 100 % de las amenazas.
  • Kenshi no sube tus archivos a internet. Solo guardamos los datos que nos das al pedir una licencia.
  • Si no logras instalar o activar Kenshi por un problema nuestro, te devolvemos el dinero dentro de los 7 días.
  • Por ahora es solo para computadoras de hogar: todavía no es apto para empresas.

1. Titular del producto

Kenshi Security (en adelante, «Kenshi», «nosotros») es un programa de seguridad para Windows desarrollado y comercializado desde Lima, Perú. Para cualquier comunicación sobre estos términos puedes escribirnos por WhatsApp al +51 992 140 169.

2. Definiciones

  • Software: la aplicación Kenshi Security para Windows, su motor de análisis, el instalador y sus actualizaciones.
  • Definiciones: las listas de huellas de malware, reglas de detección YARA y lista de sitios peligrosos que el Software descarga para funcionar.
  • Versión gratuita: las funciones del Software que se pueden usar sin licencia.
  • Licencia: el derecho de uso de las funciones de pago durante un plazo (3, 6 o 12 meses), representado por un serial firmado digitalmente.
  • Usuario o tú: la persona que descarga, instala o usa el Software, o que compra una Licencia.
  • Equipo: una computadora con Windows y una instalación del Software.
  • Extensión: la extensión «Kenshi Security - Protección web» para Google Chrome y Microsoft Edge.

3. Aceptación

Al descargar, instalar o usar el Software, o al comprar una Licencia, declaras haber leído y aceptado estos términos. Si no estás de acuerdo, no instales ni uses el Software. El Software está destinado solo a computadoras de hogar (ver el punto 24).

Si eres menor de edad, debes contar con la autorización de tus padres o tutores para comprar una Licencia.

4. El producto

4.1 Versión gratuita (sin límite de tiempo)

  • Análisis manual de archivos, carpetas, discos y memorias USB.
  • Limpieza manual de memorias USB (cuarentena de accesos directos maliciosos y recuperación de carpetas ocultas).
  • Cuarentena y restauración de archivos.
  • Actualización automática de las Definiciones.

4.2 Funciones con Licencia

  • Protección en tiempo real de las carpetas Descargas, Escritorio y Documentos.
  • Bloqueo al ejecutar: cierre de programas detectados en el momento en que se abren.
  • Análisis automático de memorias USB al conectarlas.
  • Protección web: DNS seguro y bloqueo de sitios de malware y phishing en el Equipo.

4.3 Naturaleza complementaria

Kenshi Security es una protección complementaria. No sustituye a Microsoft Defender ni a otras medidas de seguridad, y te recomendamos mantener Microsoft Defender activado. Kenshi no está certificado por laboratorios independientes de evaluación de antivirus.

5. Requisitos técnicos

  • Windows 10 o Windows 11 de 64 bits.
  • Permisos de administrador para instalar, actualizar y activar la protección web.
  • Conexión a internet para recibir Definiciones y actualizaciones, y para solicitar licencias desde la aplicación.
  • Unos 300 MB libres en disco.

En la primera instalación, Windows puede mostrar un aviso de SmartScreen porque el instalador aún no cuenta con un certificado comercial de firma de código. Para continuar se pulsa «Más información» y luego «Ejecutar de todas formas». Las actualizaciones posteriores están firmadas digitalmente por Kenshi y la aplicación verifica esa firma antes de instalarlas.

11. Cambios que Kenshi hace en tu equipo

Para protegerte, el Software realiza acciones en tu Equipo. Al aceptar estos términos las autorizas expresamente:

  • Cuarentena: mueve los archivos detectados a una carpeta aislada y neutralizada. No los borra salvo que tú lo indiques.
  • Bloqueo al ejecutar: cierra el proceso de un programa detectado en el momento en que se abre.
  • Limpieza de USB: quita los atributos de «oculto» y «sistema» que el virus de accesos directos pone a tus carpetas, y pone en cuarentena los accesos directos maliciosos.
  • Protección web (solo si la activas): cambia el DNS de tus adaptadores de red físicos a Quad9 (9.9.9.9) y añade una sección marcada como «Kenshi Security» al archivo hosts de Windows. Guarda tu configuración anterior y la restaura al desactivarla o al desinstalar.
  • Inicio con Windows: se abre en la bandeja del sistema al iniciar sesión (puedes desactivarlo en Configuración).
  • Tarea del sistema: el instalador registra una tarea programada de Windows que aplica la protección web con permisos de sistema. Se elimina al desinstalar.

Al desinstalar, se eliminan el programa, la tarea y los cambios de la protección web. Tu cuarentena y tu configuración se conservan en la carpeta de datos del usuario (%LOCALAPPDATA%\KenshiSecurity) por si vuelves a instalar; puedes borrarla tú.

  • Cada archivo de Definiciones y cada instalador está firmado digitalmente; el Software rechaza cualquier archivo cuya firma no sea válida.
  • Las actualizaciones pueden añadir, cambiar o retirar funciones. Mantendremos las funciones esenciales de tu plan mientras tu Licencia esté vigente.

  • Falsos positivos. Puede marcar como peligroso un archivo legítimo. Por eso los archivos van a cuarentena y no se borran: puedes restaurarlos.
  • Copias de seguridad. Eres responsable de mantener copias de seguridad de tu información importante.
  • El bloqueo al ejecutar actúa en fracciones de segundo, pero el programa llega a iniciarse brevemente antes de ser cerrado. La protección en tiempo real analiza los archivos después de guardarse y no impide que se abran.
  • La protección web depende de servicios de terceros (Quad9) y de listas públicas; algunos sitios peligrosos pueden no estar en ellas.

Si se determinara nuestra responsabilidad, el monto máximo será el importe que pagaste por tu Licencia vigente. Esta limitación no se aplica en casos de dolo o culpa inexcusable, ni a los derechos irrenunciables que te reconoce la ley.

  • La protección web cambia el DNS y el archivo hosts del equipo, lo que puede interferir con redes, VPN o sistemas internos de una organización.

Si se usa el Software en un entorno empresarial en contra de este punto, lo haces bajo tu exclusiva responsabilidad: no damos soporte para ese uso y, en la medida que la ley lo permita, no respondemos por los daños que se deriven de él.
